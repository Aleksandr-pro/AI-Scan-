# Дождевая вода — экспериментальный аддон для копии мира

`realistic-rain-water.mcpack` — **поведенческий** пакет, не шейдер и не текстурпак. Ориентирован на Bedrock 1.26.30+ и стабильный `@minecraft/server` 2.8.0. Пользователь сообщил версию 1.26.32.2. Реальный запуск в Minecraft и на Galaxy A15 не проверен: возможны ошибки импорта, API или производительности.

## До включения: риски

**Используйте только копию мира.** Пакет действительно помещает блоки воды и изменяет сохранение. Исходник воды может растечься, если сломать стенки углубления, вызвать затопление и повредить постройки, растения, механизмы или существ. Деактивация пакета **не отменяет изменения мира**. Нельзя гарантировать защиту построек: естественные блоки могут быть и частью сооружения. При проблемах отключите пакет и восстановите копию из резервной копии.

## Что происходит

- После наблюдаемого события начала дождя/грозы ищет открытые природные углубления в биомах равнины, леса и берёзового леса рядом с игроком. В воду превращается только воздух, окружённый по четырём сторонам полными природными блоками, над природным дном; растения и существующую воду он не заменяет. Это небольшие одно-блочные источники, не реалистичная плёнка воды на каждом блоке.
- За один проход раз в 5 секунд проверяется до 24 случайных точек для одного игрока; создаётся максимум один источник. В мире отслеживается не более 16 таких мест, включая выгруженные. Если игрок убрал воду и область загружена, место перестаёт считаться занятым. Это ограничивает работу скрипта и количество отмеченных источников, **но не объём вытекающей воды** и не исключает просадок FPS.
- После прекращения дождя создание новых источников прекращается. **Пакет не удаляет воду автоматически:** в Bedrock обычный блок воды не имеет надёжного признака владельца, и удаление по координатам могло бы стереть воду игрока. Удалите её вручную или восстановите копию мира. Это осознанное отличие от ранее предложенного автоматического высыхания.
- Используется обычное поведение воды Bedrock. Нет новой физической симуляции, реального динамического намокания всех материалов или настоящих малых волн от капель. Отражения и тени — возможности самой игры при доступном Vibrant Visuals; пакет не включает их в низком графическом режиме и не обходит ограничения GPU.
- При входе в мир скрипт не знает текущую погоду: стабильный API 2.8 сообщает об изменениях, но не предоставляет `getWeather`. Дождитесь **следующей смены погоды**. Для проверки с включёнными читами задайте `/weather clear`, затем `/weather rain`; требуется событие изменения, а не повторная установка уже действующей погоды. В сухих и снежных биомах/выше Y=100 скрипт не создаёт воду; возможны дополнительные различия от реальной погоды игры.

## Установка и проверка

1. Скопируйте мир и сделайте отдельный резервный экспорт. Откройте `realistic-rain-water.mcpack`, дождитесь импорта.
2. В настройках **копии** мира в поведенческих наборах активируйте `Дождевая вода — эксперимент`. Для него не требуется графический пакет; скриптовый API должен поддерживаться игрой и её настройками.
3. Для проверки создайте на открытой равнине яму ровно в один блок: природное дно и четыре полных природных блока по сторонам, сверху воздух. Отойдите на 5–12 блоков. После смены погоды на дождь подождите несколько минут: поиск случайный, поэтому конкретная яма не гарантирована. Если вода не появилась, проверьте сообщения об ошибках содержимого и версию API; в этой сборке выполнение в игре не проверено.
4. Если доступны Vibrant Visuals и обновлённый графический пакет `realistic-atmosphere.mcpack` v1.2.0, их можно включить отдельно. Версия 1.2 не содержит прежних луж-частиц. Если VV недоступен, аддон всё равно пытается разместить обычную воду, но не создаёт новые высококачественные тени или отражения.

## Сборка и проверки

Из корня репозитория: `python3 minecraft/tools/build_rain_water.py`, `node --experimental-default-type=module minecraft/tools/test_rain_water.mjs`, `python3 minecraft/tools/test_rain_water_archive.py`. Это структурные и модельные тесты, не проверка игрового движка.

Справка: [события изменения погоды](https://learn.microsoft.com/en-us/minecraft/creator/scriptapi/minecraft/server/weatherchangeafterevent?view=minecraft-bedrock-stable), [стабильный API 2.8 в 1.26.30](https://learn.microsoft.com/en-us/minecraft/creator/documents/update1.26.30?view=minecraft-bedrock-stable), [волны воды VV — визуальный эффект](https://learn.microsoft.com/en-us/minecraft/creator/documents/vibrantvisuals/watercustomization?view=minecraft-bedrock-stable).
