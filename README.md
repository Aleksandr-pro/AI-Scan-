# AEGIS Trade

Android-приложение для контроля торговых рисков и демо-торговли.

## Текущий этап

Доступен экран расчёта планового риска линейной позиции.

Пользователь может ввести параметры позиции, выбрать направление
и проверить расчёт относительно заданного лимита.

Приложение пока:

- не подключается к биржам;
- не получает рыночные данные;
- не совершает сделки;
- не сохраняет историю расчётов;
- не требует API-ключей.

## Требования

- Android 8.0 или новее для запуска приложения;
- JDK 17 для сборки;
- Gradle 8.9;
- Android SDK с установленной платформой API 35.

## Сборка

```bash
gradle --no-daemon testDebugUnitTest assembleDebug
```

Готовый APK:

```text
app/build/outputs/apk/debug/app-debug.apk
```

В GitHub Actions APK доступен как артефакт
`aegis-trade-debug-apk`.

## Важно

Debug APK предназначен для разработки и тестирования,
а не для публикации в Google Play.

Торговля связана с риском потери средств. Приложение
не гарантирует прибыль и не исключает ошибки или убытки.

## Расчёт риска

В проекте есть независимый модуль расчёта планового риска
для линейной позиции. Он проверяет входные данные, направление
стоп-цены и максимальный риск на сделку.

Расчёт не учитывает комиссии, проскальзывание, плечо и
ликвидацию. Фактический убыток может отличаться от планового.

Он не предназначен для инструментов с фиксированной выплатой.

## Расчёт результата демо-сделки

Добавлен независимый расчёт результата закрытия линейной
демо-позиции. Он пока не подключён к экрану и не сохраняет данные.

Расчёт не учитывает комиссии, проскальзывание, плечо и
ликвидацию. Расчётный убыток может превысить баланс.
Модель не подходит для инструментов с фиксированной выплатой.

Уже открытую демо-позицию можно рассчитать к закрытию даже
при отрицательном балансе. Правила открытия новых позиций
при таком балансе будут реализованы отдельно.
